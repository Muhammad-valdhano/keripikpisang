   - **Paket Bundling Komplit Hemat**

3. **Integrasi WhatsApp**:
   - Nomor WhatsApp: **`0895-2736-1356`** (`6289527361356`)
   - Tombol CTA Header, Tombol Hero, Tombol Footer, dan Tombol Floating WhatsApp (selalu melayang di kanan bawah layar).
   - Setiap kartu produk memiliki tombol pesan langsung dengan format template pesan otomatis yang menyebutkan nama produk yang ingin dipesan.

4. **Section Lengkap**:
   - Header & Navigasi Sticky
   - Hero Section dengan Social Proof & Value Proposition
